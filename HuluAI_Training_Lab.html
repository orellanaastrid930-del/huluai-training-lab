API contract

The backend should implement these endpoints before live controls can work.

GET /healthReturn JSON such as {"ok":true,"model_loaded":true}.
POST /chatAccept a prompt and return the model output.
POST /trainAccept an approved dataset/config and return a job ID. Training runs server-side.
GET /train/status/:idReport progress, logs, checkpoint path, and error details.

Browser security (CORS), runtime limits, GPU availability, and request formats must be handled by the backend too.
